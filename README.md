# 비트코인 P2P 계산기

구매자와 판매자가 공개 모집 조건을 만들고, 실제 결제 요청은 1:1로 검증해 전달할 수 있는 설치형 웹 앱(PWA)입니다.

## 주요 기능

- 비트코인 구매·판매 역할을 분명하게 구분
- 원화 금액, 판매자 프리미엄(%), 비트코인 수량을 즉시 계산
- 업비트 최근 체결가와 업비트 데이터랩의 업비트 프리미엄 표시
- 업비트 공개 WebSocket으로 BTC/KRW 최근 체결가를 실시간 수신하고 계산값에 반영
- mempool.space의 다음 블록·약 30분·약 1시간 권장 온체인 수수료율 표시
- 구매자와 판매자가 주고받을 금액을 거래 조건 카드로 정리
- 주소·인보이스·자금 출처·웹 링크를 제외한 공개 거래 모집 PNG 공유
- 구매자 지갑의 새 온체인 주소와 정확한 sats를 검증한 BIP 321 요청·QR 생성
- 메인넷·금액·서명·만료를 검증한 고정금액 BOLT11 요청·QR 생성
- 민감 요청은 10분 동안 탭 메모리에만 유지하고, 외부 복사·공유·저장 전에 별도 확인
- 오래되거나 갱신하지 못한 시세로는 거래 조건 공유 차단
- 홈 화면에 설치해 일반 앱처럼 실행
- iPhone Safari·Android Chrome용 홈 화면 추가 안내 이미지 제공

업비트 프리미엄은 시장 참고값입니다. P2P 계산은 화면에 표시된 업비트 가격을 기준으로 합니다. 온체인 채굴 수수료나 라이트닝 라우팅 수수료는 판매자가 별도로 부담하고, 구매자는 표시된 비트코인 수량을 그대로 받는 조건을 사용합니다.

## 데이터와 개인정보

- BTC/KRW 가격은 브라우저에서 업비트 공개 WebSocket으로 실시간 수신합니다. 화면과 계산에는 최대 1초마다 그 시점의 최신 체결값을 반영합니다.
- 최초 화면 진입 시에는 빠른 초기 표시와 WebSocket 장애 대비를 위해 한 번 REST 가격을 함께 조회할 수 있습니다.
- WebSocket 연결이 정상인 동안 `/api/market?price=0`은 업비트 REST 가격을 조회하지 않고 업비트 데이터랩 프리미엄과 mempool.space 권장 수수료율만 갱신합니다.
- 실시간 가격 연결이 정상일 때 참고값은 약 1분마다 갱신합니다. 연결 종료 또는 45초 동안 유효 ticker가 없으면 REST 가격으로 즉시 전환하고 약 16초 간격으로 갱신합니다.
- 입력한 거래 금액·판매자 프리미엄·자금 출처는 업비트 WebSocket이나 서버로 전송하지 않습니다. 허용 목록에 든 계산 초안만 이 브라우저에 12시간 저장됩니다.
- 공개 모집 PNG와 1:1 요청 PNG·QR은 사용자의 브라우저에서 생성됩니다.
- 온체인 주소와 BOLT11 인보이스는 URL·공개 모집·브라우저 저장소·서버에 넣지 않으며, 만료·이탈·명시적 삭제 때 QR 표면을 지우고 앱 상태와 참조에서 제거합니다.
- 서비스는 거래를 중개하지 않습니다. 자금 출처는 구매자가 제공한 정보이므로 거래 전에 서로 확인하세요.
- 서비스 워커는 앱 화면과 정적 파일만 저장하며 `/api/market` 시세 응답은 브라우저에 저장하지 않습니다. 서버는 외부 시세 조회를 줄이기 위해 공개 시장값만 짧게 캐시합니다.

## 운영 구조

- 계산기·설치 안내·이미지·스크립트는 정적 파일로 제공됩니다.
- BTC/KRW 최근 체결가는 업비트 공개 WebSocket `wss://api.upbit.com/websocket/v1`의 `ticker` 스트림을 브라우저에서 구독합니다.
- WebSocket이 정상일 때 BTC 가격은 WebSocket만 사용하며, 주기적인 REST 가격 조회는 하지 않습니다.
- `/api/market?price=0`은 시장 프리미엄과 온체인 수수료율만 조회합니다.
- `/api/market?price=1`은 최초 표시 또는 WebSocket 장애 시에만 업비트 REST 가격을 함께 조회하는 안전망입니다.
- WebSocket은 30초 간격으로 ping을 보내고 45초 동안 유효 ticker가 없으면 닫습니다. 연결 종료 후 REST 시세로 전환하며 12초 뒤 재연결을 시도합니다.
- 외부 조회가 잠시 실패하면 최근 성공값을 확인용으로 표시하되, 오래되거나 갱신하지 못한 시세로는 거래 조건을 공유할 수 없습니다.
- 거래 금액·판매자 프리미엄·선택한 자금 출처는 시세 API나 WebSocket에 전달되지 않습니다.

## 로컬 실행

Node.js 22.13 이상, 23 미만을 사용합니다.

```bash
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run check:worker
```

## 배포

Cloudflare 로그인 후 아래 명령으로 정적 PWA와 시세 전용 Worker를 함께 배포합니다.

```bash
npm run deploy
```

`npm run deploy`는 현재 운영 Worker 이름을 사용합니다. 검토 브랜치에서는 실행하지 말고 `npm run check:worker`로 dry-run만 수행하세요. 원격 미리보기가 필요하면 운영과 이름·route가 분리된 Cloudflare 환경을 먼저 구성해야 합니다. Production 반영은 승인된 `main`에서만 실행하세요.
