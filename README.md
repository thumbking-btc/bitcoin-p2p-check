# 비트코인 P2P 계산기

구매자와 판매자가 한 화면에서 거래 조건을 확인하고 이미지로 공유할 수 있는 설치형 웹 앱(PWA)입니다.

## 주요 기능

- 비트코인 구매·판매 역할을 분명하게 구분
- 원화 금액, 판매자 프리미엄(%), 비트코인 수량을 즉시 계산
- 업비트 최근 체결가와 업비트 데이터랩의 업비트 프리미엄 표시
- mempool.space의 다음 블록·약 30분·약 1시간 권장 온체인 수수료율 표시
- 구매자와 판매자가 주고받을 금액을 거래 조건 카드로 정리
- 현재 기준 가격과 조회 시각을 포함한 거래 조건 PNG 공유
- 오래되거나 갱신하지 못한 시세로는 거래 조건 공유 차단
- 홈 화면에 설치해 일반 앱처럼 실행
- iPhone Safari·Android Chrome용 홈 화면 추가 안내 이미지 제공

업비트 프리미엄은 시장 참고값입니다. P2P 계산은 화면에 표시된 업비트 가격을 기준으로 합니다. 이 계산기는 온체인 송금 수수료를 판매자가 별도로 부담하고, 구매자는 표시된 비트코인 수량을 그대로 받는 거래 조건을 사용합니다.

## 데이터와 개인정보

- 가격은 업비트 최근 체결가, 시장 프리미엄은 업비트 데이터랩 값, 온체인 수수료율은 mempool.space 권장값을 서버에서 조회합니다.
- 입력한 거래 금액·판매자 프리미엄·자금 출처는 서버로 전송하거나 저장하지 않습니다.
- 거래 조건 PNG는 사용자의 브라우저에서 생성됩니다.
- 서비스는 거래를 중개하지 않습니다. 자금 출처는 구매자가 제공한 정보이므로 거래 전에 서로 확인하세요.
- 서비스 워커는 앱 화면과 정적 파일만 저장하며 `/api/market` 시세 응답은 브라우저에 저장하지 않습니다. 서버는 외부 시세 조회를 줄이기 위해 공개 시장값만 짧게 캐시합니다.

## 운영 구조

- 계산기·설치 안내·이미지·스크립트는 정적 파일로 제공됩니다.
- `/api/market`만 작은 Cloudflare Worker가 실행되어 업비트 가격·시장 프리미엄·온체인 수수료율을 조회합니다.
- 외부 조회가 잠시 실패하면 최근 성공값을 확인용으로 표시하되, 오래되거나 갱신하지 못한 시세로는 거래 조건을 공유할 수 없습니다.
- 거래 금액·판매자 프리미엄·선택한 자금 출처는 시세 API에 전달되지 않습니다.

## 로컬 실행

Node.js 22.19.0을 사용합니다.

```bash
npm ci
npm run dev
npm test
npm run build
```

## 배포

Cloudflare 로그인 후 아래 명령으로 정적 PWA와 시세 전용 Worker를 함께 배포합니다.

```bash
npm run deploy
```

### Git 브랜치

- `main`: Cloudflare Production 배포용 브랜치
- `staging`: Cloudflare Preview 검증용 브랜치이며 `staging` Preview alias를 사용합니다.

컴퓨터나 개발 도구를 켜 두지 않아도 배포된 서비스는 계속 동작합니다. 초기 규모에서는 Cloudflare Workers 무료 한도 안에서 운영할 수 있으며, 사용량이 커지면 계정의 사용량과 과금 설정을 확인해야 합니다.
